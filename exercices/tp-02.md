# TP 2 — Compiler et installer un module de noyau

> Module : 2 — Modules de noyau, /proc, /sys et dépannage matériel
> Durée estimée : 1h
> Difficulté : 3 / 5
> Type : Travaux pratiques guidés

## Mise en situation

Pour exposer une métrique métier (un compteur incrémenté à la demande) à l'espace utilisateur sans modifier le noyau, vous devez écrire, compiler et installer un module de noyau out-of-tree qui crée une entrée `/proc/lab_counter`. Ce module servira de socle pour des extensions ultérieures.

## Objectifs

- Écrire un module de noyau minimal en C
- Compiler le module avec un Makefile out-of-tree
- Charger, paramétrer, décharger le module et observer ses effets
- Gérer les dépendances et la persistance via `/etc/modules-load.d/`

## Prérequis techniques

### Logiciels à installer

- VM Linux (Debian 12 ou Ubuntu 22.04+) avec accès sudo
- Headers du noyau actif : `linux-headers-$(uname -r)`
- `build-essential`, `make`

### Vérification de l'environnement

```bash
uname -r
ls /lib/modules/$(uname -r)/build
gcc --version
```

Le lien `build` doit pointer vers les headers installés.

## Architecture cible

```
~/lab-module/
  hello.c
  Makefile
  README.md          (vos notes)

Après chargement :
/proc/lab_counter    (lecture: valeur courante, écriture: incrémente)
/sys/module/hello/parameters/start_value
```

## Étapes

### Étape 1 — Préparer l'environnement (5 min)

Objectif : installer les paquets requis.

1. Installer les paquets :
   ```bash
   sudo apt update
   sudo apt install -y build-essential linux-headers-$(uname -r)
   ```

2. Créer le répertoire de travail :
   ```bash
   mkdir -p ~/lab-module
   cd ~/lab-module
   ```

Point de contrôle : `ls /lib/modules/$(uname -r)/build/Makefile` existe.

### Étape 2 — Écrire le module (15 min)

Objectif : un module qui expose `/proc/lab_counter`.

1. Créer `hello.c` avec le contenu suivant :
   ```c
   #include <linux/module.h>
   #include <linux/kernel.h>
   #include <linux/init.h>
   #include <linux/proc_fs.h>
   #include <linux/uaccess.h>
   #include <linux/atomic.h>

   static int start_value = 0;
   module_param(start_value, int, 0444);
   MODULE_PARM_DESC(start_value, "Valeur initiale du compteur");

   static atomic_t counter;
   static struct proc_dir_entry *entry;

   static ssize_t lab_read(struct file *f, char __user *u, size_t s, loff_t *o) {
       char buf[32];
       int len;
       if (*o > 0) return 0;
       len = snprintf(buf, sizeof(buf), "%d\n", atomic_read(&counter));
       if (copy_to_user(u, buf, len)) return -EFAULT;
       *o = len;
       return len;
   }

   static ssize_t lab_write(struct file *f, const char __user *u, size_t s, loff_t *o) {
       atomic_inc(&counter);
       return s;
   }

   static const struct proc_ops lab_ops = {
       .proc_read  = lab_read,
       .proc_write = lab_write,
   };

   static int __init lab_init(void) {
       atomic_set(&counter, start_value);
       entry = proc_create("lab_counter", 0666, NULL, &lab_ops);
       if (!entry) return -ENOMEM;
       pr_info("lab_counter loaded, start=%d\n", start_value);
       return 0;
   }

   static void __exit lab_exit(void) {
       proc_remove(entry);
       pr_info("lab_counter unloaded\n");
   }

   module_init(lab_init);
   module_exit(lab_exit);
   MODULE_LICENSE("GPL");
   MODULE_AUTHOR("Stagiaire LUX-ADMA");
   MODULE_DESCRIPTION("Compteur exposé via /proc");
   ```

2. Créer `Makefile` :
   ```make
obj-m += hello.o

all:
   make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules

clean:
   make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean
   ```

Point de contrôle : le tab dans le Makefile est bien un tab et pas des espaces.

### Étape 3 — Compiler le module (5 min)

1. Lancer la compilation :
   ```bash
   make
   ls -l hello.ko
   modinfo ./hello.ko
   ```

Point de contrôle : `hello.ko` est produit, `modinfo` affiche le paramètre `start_value` et la licence GPL.

### Étape 4 — Charger et tester (10 min)

1. Charger sans paramètre :
   ```bash
   sudo insmod ./hello.ko
   lsmod | grep hello
   dmesg | tail -3
   cat /proc/lab_counter
   ```

2. Incrémenter et relire :
   ```bash
   echo x | sudo tee /proc/lab_counter
   echo x | sudo tee /proc/lab_counter
   cat /proc/lab_counter
   ```

3. Décharger, recharger avec une valeur initiale :
   ```bash
   sudo rmmod hello
   sudo insmod ./hello.ko start_value=100
   cat /proc/lab_counter
   cat /sys/module/hello/parameters/start_value
   ```

Point de contrôle : la lecture initiale renvoie 100 et chaque écriture incrémente la valeur.

### Étape 5 — Installation système (15 min)

Objectif : rendre le module disponible via `modprobe`.

1. Copier le `.ko` dans l'arborescence noyau :
   ```bash
   # le repertoire extra/ n'existe pas par defaut : le creer d'abord
   sudo mkdir -p /lib/modules/$(uname -r)/extra
   sudo install -o root -g root -m 0644 hello.ko \
       /lib/modules/$(uname -r)/extra/hello.ko
   sudo depmod -a
   ```

2. Décharger l'instance courante puis charger via modprobe :
   ```bash
   sudo rmmod hello 2>/dev/null
   sudo modprobe hello start_value=42
   cat /proc/lab_counter
   ```

3. Charger automatiquement au boot :
   ```bash
   echo "hello" | sudo tee /etc/modules-load.d/hello.conf
   echo "options hello start_value=10" | sudo tee /etc/modprobe.d/hello.conf
   ```

Point de contrôle : `sudo modprobe -r hello && sudo modprobe hello` repart de la valeur 10.

### Étape 6 — Nettoyage (5 min)

1. Décharger et désinstaller :
   ```bash
   sudo rmmod hello
   sudo rm /lib/modules/$(uname -r)/extra/hello.ko
   sudo rm /etc/modules-load.d/hello.conf /etc/modprobe.d/hello.conf
   sudo depmod -a
   make clean
   ```

Point de contrôle : `lsmod | grep hello` ne retourne rien et `/proc/lab_counter` n'existe plus.

## Pour aller plus loin

- Ajouter un paramètre booléen `verbose` qui logue chaque incrémentation
- Exposer le compteur en lecture/écriture via `/sys/kernel/lab_counter` au lieu de `/proc`
- Écrire une `Kbuild` au lieu d'un `Makefile` simple et étudier la différence
- Empaqueter le module en `.deb` avec `dkms` pour reconstruction automatique à chaque mise à jour du noyau
