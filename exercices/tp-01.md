# TP 1 — Compiler et installer un noyau personnalisé en méthode Debian

> Module : 1 — Architecture système Linux et compilation du noyau
> Durée estimée : 1h30
> Difficulté : 3 / 5
> Type : Travaux pratiques guidés

## Mise en situation

Votre équipe envisage d'évaluer un noyau Linux 6.x récent pour valider la prise en charge d'une carte réseau spécifique. Vous devez préparer un noyau compilé maison, packagé en `.deb`, installable et désinstallable proprement sur un serveur Debian 12 de test.

## Objectifs

- Récupérer les sources d'un noyau Linux et les outils de compilation
- Configurer un noyau à partir du `.config` du noyau actif
- Compiler et générer des paquets Debian installables
- Démarrer sur le nouveau noyau et revenir au précédent en cas de problème

## Prérequis techniques

### Logiciels à installer

- VM Debian 12 avec 4 vCPU, 4 Go de RAM, 30 Go de disque, accès sudo
- Connexion Internet
- Outils : `build-essential`, `bc`, `bison`, `flex`, `libssl-dev`, `libelf-dev`, `libncurses-dev`, `kmod`, `cpio`, `rsync`, `dwarves`

### Vérification de l'environnement

```bash
uname -a
nproc
df -h /usr/src
free -h
```

Confirmer au moins 4 Go RAM, 4 cores et 15 Go libres dans `/usr/src`.

## Architecture cible

```
/usr/src/
  linux-6.6.x/                 (sources)
  linux-image-6.6.x_..._amd64.deb
  linux-headers-6.6.x_..._amd64.deb
/boot/
  vmlinuz-6.6.x-custom         (après installation)
  initrd.img-6.6.x-custom
GRUB
  entrée Debian 6.6.x-custom (par défaut)
  entrée Debian 6.1.x (fallback)
```

## Étapes

### Étape 1 — Préparation de l'environnement (10 min)

Objectif : disposer de tous les outils de build et avoir libéré l'espace nécessaire.

1. Installer les paquets requis :
   ```bash
   sudo apt update
   sudo apt install -y build-essential bc bison flex libssl-dev libelf-dev \
       libncurses-dev kmod cpio rsync dwarves wget xz-utils
   ```

2. Se positionner dans `/usr/src` :
   ```bash
   cd /usr/src
   sudo chown $USER:$USER .
   ```

Point de contrôle : `gcc --version`, `make --version` et `dpkg-deb --version` répondent.

### Étape 2 — Récupération et extraction des sources (10 min)

Objectif : obtenir l'arbre source d'un noyau LTS récent.

1. Télécharger l'archive (version au choix, 6.6 LTS recommandé pour le TP) :
   ```bash
   wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.6.30.tar.xz
   tar xf linux-6.6.30.tar.xz
   cd linux-6.6.30
   ```

2. Vérifier l'intégrité :
   ```bash
   ls -lh
   head Makefile
   ```

Point de contrôle : la version dans les premières lignes du `Makefile` correspond à la version téléchargée.

### Étape 3 — Configuration du noyau (15 min)

Objectif : repartir de la configuration du noyau distro et l'ajuster.

1. Copier la configuration courante :
   ```bash
   cp /boot/config-$(uname -r) .config
   ```

2. Mettre à jour la config aux nouveaux défauts puis désactiver le mode debug verbeux :
   ```bash
   make olddefconfig
   scripts/config --disable DEBUG_INFO
   scripts/config --disable DEBUG_INFO_DWARF5
   scripts/config --disable DEBUG_INFO_BTF
   scripts/config --set-str LOCALVERSION "-custom"
   scripts/config --disable SYSTEM_TRUSTED_KEYS
   scripts/config --disable SYSTEM_REVOCATION_KEYS
   make olddefconfig
   ```

Point de contrôle : `grep LOCALVERSION .config` retourne `CONFIG_LOCALVERSION="-custom"`.

### Étape 4 — Compilation et packaging (35 min)

Objectif : produire les paquets `.deb` installables.

1. Lancer la compilation et le packaging :
   ```bash
   make -j$(nproc) bindeb-pkg
   ```

2. Pendant que ça compile, ouvrir une autre console et regarder l'usage :
   ```bash
   top
   df -h /usr/src
   ```

3. À la fin, lister les paquets produits dans le répertoire parent :
   ```bash
   ls -lh ../linux-*-6.6.30-custom*.deb
   ```

Point de contrôle : 4 paquets `.deb` (image, headers, libc-dev, dbg) sont présents et la compilation s'est terminée sans erreur.

### Étape 5 — Installation et test du nouveau noyau (15 min)

Objectif : installer, redémarrer dessus, vérifier.

1. Installer image et headers (les seuls indispensables) :
   ```bash
   cd ..
   sudo dpkg -i linux-image-6.6.30-custom_*.deb linux-headers-6.6.30-custom_*.deb
   ```

2. Vérifier que GRUB a bien intégré l'entrée :
   ```bash
   grep -E "menuentry '|6.6.30" /boot/grub/grub.cfg | head
   ```

3. Redémarrer et choisir l'entrée 6.6.30-custom au menu GRUB.

4. Une fois redémarré :
   ```bash
   uname -r
   uname -a
   dmesg | head -5
   ```

Point de contrôle : `uname -r` retourne `6.6.30-custom`.

### Étape 6 — Retour arrière propre (5 min)

Objectif : savoir désinstaller le noyau de test.

1. Redémarrer sur le noyau d'origine via GRUB.
2. Désinstaller le noyau custom :
   ```bash
   sudo apt purge linux-image-6.6.30-custom linux-headers-6.6.30-custom
   sudo update-grub
   ls /boot/
   ```

Point de contrôle : `vmlinuz-6.6.30-custom` n'est plus présent et l'entrée GRUB associée a disparu.
